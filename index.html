How I work

Map. Build. Test. Hand over.

The same four steps on every workflow, whatever the tool.

01

Map the work

I write down the outcome, inputs, decisions and handoffs, and time the manual baseline so every gain can be measured.

02

Build it

I build the workflow myself in n8n, Make or code, with Claude doing the heavy lifting inside clear instructions.

03

Test it

I run real inputs and awkward exceptions, and check accuracy, effort, turnaround and cost against the baseline.

04

Hand it over

A one page operating guide, a trained team and a named owner for exceptions, so the workflow outlasts me.
